# nrxp-servo — форк Servo под этот браузер

План доработки недостающего функционала движка лежит в самом форке: **`~/netrunner/nrxp-servo/docs/nrxp/PLAN.md`**
(ветка `nrxp/0.7`, база — тег `v0.7.0`, remote `upstream` = `servo/servo`). Репозиторий на GitHub/Gitea для форка **не создавался**.

Кратко (этапы N0–N14): бутстрап и сборка по путям → срочные исправления (WebGL при остановке, хранилище без профиля, prefs,
PerformanceObserver) → **сеть через коннектор встраивателя** (NRXP без loopback-прокси; фундамент для остальных) → загрузки →
данные сайтов → поиск по странице → печать/PDF → медиа и MSE → Service Workers → WebRTC через туннель → HTTP/3 → пароли/формы/a11y →
мультипроцесс и песочница → расширения → сопровождение форка и апстрим.

Что можно сделать в браузере **без** форка уже сейчас: загрузки по эвристике с куками (`SiteDataManager::cookies_for_url`, N3a) и
поиск по странице через `evaluate_javascript` (N5a).

Связь с итерациями браузера: I6.1 (загрузки) ← N3; I10 (HTTP/3) ← N10; I11 (герметичность, остаток) ← N2, N12; I13 ← N7, N8;
I12 (расширения) ← N13.
